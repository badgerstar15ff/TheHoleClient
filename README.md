## ❗ Что входит в комплект, а что нужно отдельно

**TheHoleClient — это графическая оболочка** над сетевыми ядрами.

| | |
|---|---|
| Есть ли внутри Xray / sing-box? | **Да.** Ядра, `geoip.dat`, `geosite.dat` и `wintun.dll` лежат в папке `core` рядом с программой. |
| Нужно ли что-то ставить для VPN-режима? | **Нет.** Достаточно подписки или ссылки на сервер. |
| Есть ли внутри Zapret? | **Нет.** Ни `winws.exe`, ни драйвера WinDivert. Для режима Zapret его нужно скачать отдельно и указать папку в настройках. |

## Что умеет

- **Два режима в одном окне:** VPN и Zapret переключаются без перезапуска.
- **Два ядра на выбор** — [Xray-core](https://github.com/XTLS/Xray-core) и [sing-box](https://github.com/SagerNet/sing-box).
- **Ссылки:** `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://` / `hy2://`.
- **Подписки** — добавление по URL, автообновление, полные Xray-конфиги от панелей (формат Happ, балансировщики, правила провайдера).
- **Режимы туннеля** — локальный прокси (SOCKS / HTTP) или TUN через `wintun.dll`, плюс Kill switch.
- **Маршрутизация и DNS** — несколько режимов, блокировка рекламы, свои списки доменов, DoH / TCP / QUIC, FakeDNS.
- **Профили** — сохранённые наборы настроек с быстрым переключением.
- **Пинг серверов** — TCP-пинг всех серверов, сортировка, флаги стран.
- **Статус** — таймер подключения, график скорости ↑↓, проверка публичного IP.
- **Zapret** — запуск и остановка стратегий `.bat`, проверка стратегий пингом, редактор доменных списков.
- **TG WS Proxy** — запуск прокси для Telegram одной кнопкой.
- **Трей и автозапуск** — сворачивание в трей, запуск вместе с Windows, автоподключение.

## Установка

1. Скачай готовую сборку из раздела [Releases](https://github.com/badgerstar15ff/TheHoleClient/releases) — и только оттуда.
2. Запусти программу и подтверди запрос прав администратора. Они нужны для TUN и Zapret.
3. Для режима VPN больше ничего ставить не нужно: ядра уже лежат в папке `core`.

```
TheHoleClient/
├── TheHoleClient.exe
└── core/
    ├── xray.exe
    ├── sing-box.exe
    ├── geoip.dat
    ├── geosite.dat
    └── wintun.dll
```

- Не удаляй и не перемещай папку `core`: клиент ищет ядра только рядом с программой.
- Если папка `core` пропала, клиент попробует восстановить её из `core_backup`.
- **Для полных конфигов подписок нужен Xray**, а sing-box работает с отдельными ссылками.
- Чтобы обновить ядро, замени файл в `core` и перезапусти клиент.
- Для режима Zapret скачай [Zapret](https://github.com/bol-van/zapret) отдельно и укажи его папку в настройках (см. [Режим Zapret](#режим-zapret)).

**Требования:** Windows 10/11 (x64), права администратора.

> ⚠️ Не скачивай программу со сторонних сайтов и из «сборок» — неизвестно, что в них добавлено.

## Первый запуск

1. Запусти клиент и подтверди UAC. Это обязательное условие, а не баг.
2. Вставь ссылку на подписку или сервер (`Ctrl+V` или кнопка добавления).
3. Выбери сервер. При желании проверь пинг: `Ctrl+P`.
4. Нажми на большую кнопку питания. Появятся таймер и скорость.

**Горячие клавиши:** `F5` — обновить подписки, `Ctrl+P` — пинг серверов (в режиме Zapret — проверка стратегий), `Ctrl+V` — вставить ссылку.

## Режим VPN

| Что | Подробности |
|---|---|
| **Ядро** | Xray-core или sing-box (Настройки → ядро) |
| **Туннель** | Прокси (SOCKS `10808`, HTTP `10809` по умолчанию) или TUN |
| **Kill switch** | Блокирует DNS и трафик мимо туннеля (Windows Filtering Platform) |
| **Маршруты** | Все сайты через VPN, свой профиль (только домены из `list-general.txt`), правила провайдера |
| **DNS** | Удалённый (через туннель) и прямой; форматы `1.1.1.1`, `https://…/dns-query`, `tcp://…`, `quic+local://…` |
| **Дополнительно** | Sniffing, Mux, фрагментация TLS ClientHello, уровень логов |

**Про ядра.** Xray поддерживает полные конфиги подписок и балансировщики. sing-box работает с отдельными ссылками VLESS, VMess, Trojan и Hysteria2; полные Xray-конфиги подписок через него пока не конвертируются.

**Подписки.** Панели (Remnawave, Marzban и др.) выбирают формат ответа по User-Agent. В настройках можно выбрать Happ, v2rayN, INCY или свой. HWID отправляется автоматически (всем, кроме публичных ссылок вроде GitHub), всегда, никогда или задаётся вручную.

## Режим Zapret

1. Открой Настройки → **Zapret** и укажи папку, где лежат стратегии `*.bat` и `bin\winws.exe`.
2. Нажми «Проверить компоненты Zapret».
3. Выбери стратегию и нажми кнопку запуска. Для запуска `winws.exe` нужны права администратора.

| Режим списков | Что происходит |
|---|---|
| **Только выбранные сайты** | Обрабатываются домены из списков выбранной стратегии |
| **Все сайты** | Обрабатывается весь трафик |
| **Всё кроме исключений** | Домены из `list-exclude.txt` не обрабатываются |

- **Проверка стратегий** (`Ctrl+P`): запуск → пинг → остановка для каждой стратегии, результат рисуется как у серверов VPN.
- **Редактор списков** — правка `list-general.txt` и `list-exclude.txt` прямо в окне.
- Клиент создаёт временные файлы `__cobalt_*_mode.bat`, а ваши `.bat` не меняет.
- **TG WS Proxy:** укажи путь к `tgwsproxy.exe` в настройках или выбери его при первом нажатии «Получить прокси для ТГ».

## Настройки

| Вкладка | Что там |
|---|---|
| **Ядро / Основное** | Выбор ядра, режим туннеля, Kill switch, порты |
| **Маршруты** | Режим маршрутизации, блокировка рекламы, обход приватных адресов, списки доменов |
| **Профили** | Сохранение и загрузка наборов настроек |
| **DNS** | Удалённый и прямой DNS, FakeDNS |
| **Дополнительно** | Sniffing, Mux, фрагментация, уровень логов |
| **Подписки** | User-Agent, HWID, автообновление, URL и таймаут пинга |
| **Zapret** | Пути к Zapret и TG WS Proxy, режим списков, звуки |
| **Приложение** | Автозапуск, запуск в трей, автоподключение, папка с данными |

В режиме Zapret показываются только вкладки «Zapret» и «Приложение».

## Если что-то не работает

**«Ядро Xray / sing-box не найдено»**
: Папка `core` должна лежать рядом с программой. Если файлы удалил антивирус или ты сам, верни их из `core_backup` или переустанови программу из Releases.

**Не найдены `geoip.dat` / `geosite.dat`**
: Эти файлы должны лежать в `core` рядом с `xray.exe`. Верни их из `core_backup` или замени на актуальные.

**TUN не включается**
: Нужны права администратора и `wintun.dll` в папке `core`.

**Ядро завершается сразу после запуска**
: Открой журнал в клиенте. Обычно ссылка повреждена, протокол не поддерживается выбранным ядром или порт занят другой программой.

**«Не найден winws.exe»**
: Положи `winws.exe` в `bin\` внутри папки Zapret и проверь путь в настройках.

**Подключился к Zapret, но сайты не открываются**
: Стратегия не подходит провайдеру. Запусти проверку стратегий (`Ctrl+P`) и выбери ту, у которой лучший пинг.

**Подписка не загружается**
: Ссылка должна начинаться с `https://`. Попробуй сменить User-Agent на Happ, v2rayN или INCY.

## Про антивирус

Windows Defender и SmartScreen могут ругаться на программу. Причины:

- запрос прав администратора при запуске;
- запуск сетевых ядер и работа с драйверами (`wintun`, WinDivert);
- сборка без цифровой подписи.

Антивирус может также удалить файлы из папки `core`. Если так случилось, добавь папку программы в исключения и верни файлы.

Это ложное срабатывание. При предупреждении SmartScreen: «Подробнее» → «Выполнить в любом случае».
